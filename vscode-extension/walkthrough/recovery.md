# Create a recovery code

The vault key is kept in your OS credential store. If that store is lost (new computer,
Windows reset, broken profile), the vault cannot be opened without a backup.

A recovery code is a one-time, 32-character code. SealBox shows it once in a separate
window; write it down or save it in your password manager. You can also split it into
three shares, any two of which are enough.

Working in a team? Share the vault through your teammates' GitHub SSH keys instead:
**SealBox: Add Teammate**.
